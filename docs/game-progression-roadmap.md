# ゲーム成長系の続き

2026-10-17 の相談に基づく作業メモ。下記の「次の実装」は未実装。

## 今回の土台

- アイテム定義に使用回数。既存武器は30、消耗品は1で移行する。
- 武器は正答による攻撃一回につき一回消耗。ターン内で壊れたら、その後の攻撃に装備加算を使わない。
- 個数と使用中の一個の残回数を分離。付け外しで回復しない。予備を自動装備しない。
- 毒はターン末HP減少、呪いはMP減少。敵の命中時スキルとして付与可能。付与の次ターンから有効、戦闘終了で解除。
- 通常の攻防の打撃を対象アイコン上に表示。敵を中央・等間隔配置。
- 実績に総歩数を表示。導入前の履歴から推測せず、今後消費した歩数を累積する。

## 次の実装

1. スキル獲得経路をLv・ショップ装備・専門分野に整理する。
2. adminにジョブ管理。専門分野ごとに一ジョブを選び、達成度・Powerに応じた能力補正とスキル習得を定義する。
3. 配合では親のジョブを片方選択。指定の組合せによる上位ジョブ開放と、育成方向が見えるジョブ一覧。
4. トリガーを「対象（敵／味方）＋条件」に整理。能力値の絶対値／割合の上下比較、最大／最小対象、buff／debuffの重複数、状態異常の有無を扱う。
5. トリガーのショップ購入と所持を導入。ガンビット枠は初期1、Lvアップに加えて購入でも増やせる方向（以前の「Lvのみ」から今回変更）。
6. 敵にもスキル・ガンビット。通常の攻防を既定の行動とし、未設定でも通常戦闘ができるようにする。

## 仮置き

- 魔攻・魔防はまだ追加しない。攻守を分離する必要が実際の調整で明確になってから判断する。
- ガンビットはキャラごとにターン末一行動。通常の復習クイズの操作量を増やさない。
- ジョブ、スキル、トリガーの所持・解放と、スキル自体の効果定義を混ぜない。
